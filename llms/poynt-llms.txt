# Poynt (GoDaddy Poynt)

> Poynt is an open commerce platform for merchants built around smart payment terminals and the Poynt Cloud API (services.poynt.net). Developers build and distribute business apps that manage orders, transactions, customers, products, catalogs, inventory, taxes and businesses, subscribe to real-time webhooks, and tokenize card data in the browser with Poynt Collect. Authentication is OAuth 2.0 via a self-signed JWT bearer grant.

## APIs

- [Poynt Cloud API reference](https://docs.poynt.com/api-reference/index.html): REST API at https://services.poynt.net for orders, transactions, customers, products, catalogs, inventory, taxes, businesses and webhooks.

## Authentication

- OAuth 2.0. A self-signed JWT (signed with the app's registered RSA key) is POSTed to https://services.poynt.net/token using grant urn:ietf:params:oauth:grant-type:jwt-bearer and exchanged for a short-lived access token sent as `Authorization: Bearer <token>` with an `Api-Version: 1.2` header.

## Conventions

- Idempotency via the `POYNT-REQUEST-ID` header on state-changing requests.
- Versioning via the `Api-Version` header (current 1.2).
- JSON request/response bodies; standard HTTP status codes.
